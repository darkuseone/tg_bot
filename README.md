# Бот Markus Brown

Бот продаёт цифровые продукты в Telegram и принимает оплату только звёздами. Первый продукт — курс «PIXEL VERSE · Мультстудия в кармане», 990 ⭐. Бот живёт на Cloudflare Workers (бесплатный тариф) и хранит покупки в базе D1. Сервер арендовать не нужно.

Человек нажимает «Старт» или кнопку меню «Открыть» и попадает в мини-приложение. Там карточка курса и оплата звёздами. После оплаты файлы по-прежнему приходят в чат.

## Что сделать один раз

### 1. Бот в BotFather

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя: **Markus Brown**.
3. Username должен заканчиваться на `bot`, например `markusbrown_bot`.
4. BotFather пришлёт токен. Это пароль бота. Не присылай его в чат и не клади в файлы репозитория.
5. Аватар ставится только руками: в BotFather команда `/setuserpic`. Подойдёт подготовленное фото или монограмма. Сам бот аватар не меняет.
6. Описание и меню команд бот записывает себе сам при запуске. Их не нужно набирать в BotFather.

Свой числовой Telegram ID узнай в [@userinfobot](https://t.me/userinfobot). Это `ADMIN_ID`. Команды автора работают только с него.

### 2. Аккаунт Cloudflare

1. Зарегистрируйся на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up). Карту не спрашивают.
2. Справа сверху: My Profile → API Tokens → Create Token.
3. Шаблон **Edit Cloudflare Workers**.
4. Нажми **+ Add more** и добавь право **Account → D1 → Edit**.
5. Create Token. Токен показывается один раз. Это `CLOUDFLARE_API_TOKEN`.
6. Account ID: слева Workers & Pages, столбец справа. Это `CLOUDFLARE_ACCOUNT_ID`.

### 3. Секреты

Четыре значения кладутся в секреты Cursor (Dashboard → Cloud Agents → Secrets), не в чат:

| Имя | Что это |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен из BotFather |
| `CLOUDFLARE_API_TOKEN` | токен Cloudflare |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID |
| `ADMIN_ID` | твой числовой Telegram ID |

В коде этих значений нет. В логах бот их тоже не печатает.

## Как бот выкладывается

Агент создаёт базу D1 `markus-brown`, применяет миграции, выкладывает Worker и прописывает секреты Worker:

- `TELEGRAM_BOT_TOKEN`
- `ADMIN_ID`
- `WEBHOOK_SECRET` — случайная строка, её придумывает запуск, в чат она не попадает

Потом бот регистрирует вебхук, имя, описание и меню команд.

Если выкладываешь сам, из папки проекта:

```bash
npx wrangler d1 create markus-brown
```

Вставь полученный `database_id` в `wrangler.jsonc` вместо нулей. Дальше:

```bash
npx wrangler d1 migrations apply markus-brown --remote
npx wrangler deploy
```

Секреты Worker передаются через stdin, чтобы они не остались в истории команд:

```bash
printf '%s' "$TELEGRAM_BOT_TOKEN" | npx wrangler secret put TELEGRAM_BOT_TOKEN
printf '%s' "$ADMIN_ID" | npx wrangler secret put ADMIN_ID
printf '%s' "$WEBHOOK_SECRET" | npx wrangler secret put WEBHOOK_SECRET
```

`WEBHOOK_SECRET` — длинная случайная строка из букв и цифр. Затем:

```bash
WORKER_URL=https://markus-brown.<твой-поддомен>.workers.dev npm run setup
```

Адрес `workers.dev` печатает `wrangler deploy`. Команда `setup` вызывает `getMe` и `getWebhookInfo` и печатает username и адрес вебхука, без токена.

Проверка руками: открой `https://<worker>.workers.dev/` — ответ `{"ok":true,"service":"markus-brown"}`.

## Мини-приложение

Оно открывается с того же адреса, что и бот: `https://markus-brown.<поддомен>.workers.dev/app`.

- Кнопка меню в чате — «Открыть». Её ставит запуск бота.
- `/start` пишет две строки и даёт одну кнопку «Открыть».
- Оплата из приложения: счёт Stars на 990. Пока `TEST_MODE` равен `"1"`, у владельца на кнопке 1 ⭐. Повторная покупка новый счёт не создаёт.
- Кнопка «Open» в профиле бота ставится только в [@BotFather](https://t.me/BotFather): Bot Settings → Configure Mini App → Enable Mini App, адрес `/app`. Без этого `t.me/<бот>` открывает чат, а не приложение.

## Картинки

В мини-приложении две картинки из папки `assets`:

- фото Markus Brown на главной, маленькое и пиксельное, на анимированном красном фоне;
- обложка PIXEL VERSE на экране курса.

`/setimage` по-прежнему сохраняет фото в базу, но экран мини-приложения берёт файлы из `assets`, не из базы.

## Файлы курса

Пока файлы не загружены, оплата проходит, но бот честно пишет, что файлов ещё нет.

1. Отправь `/setfiles pixelverse`.
2. Пришли четыре файла по одному, как **файл**, не как сжатое фото. Порядок: курс, промты, чек-листы, `starter-kit.zip`.
3. Если есть ролик `promo.mp4`, его можно прислать как видео. В покупку он не входит, мини-приложение его не показывает.
4. Отправь `/done`.

Подписи бот проставит сам, если ты не написал свою. Проверка: `/mycourse` после тестовой покупки присылает те же файлы. Наружу ссылки на файлы не выдаются.

## Тестовая покупка

В `wrangler.jsonc` переменная `TEST_MODE` сейчас `"1"`. Пока она включена, **только ты** (аккаунт `ADMIN_ID`) платишь 1 ⭐. У всех остальных на кнопке и в счёте остаётся 990 ⭐. Та же цена проверяется перед списанием: чужой счёт на 1 ⭐ бот отклонит.

1. Загрузи файлы, как выше.
2. Открой мини-приложение, зайди в PIXEL VERSE и нажми «Оплатить». У тебя на кнопке 1 ⭐, у остальных 990 ⭐. Нажатие сразу открывает счёт.
3. Оплати. В чат придёт текст и файлы. Тебе же придёт сообщение «Новая покупка».
4. Верни звёзды: `/refund <твой id> pixelverse`. Свой id — это `ADMIN_ID`. После возврата «Мои покупки» файлы уже не отдаёт.
5. Выключи тест: в `wrangler.jsonc` поставь `"TEST_MODE": "0"` и снова выполни `npx wrangler deploy`. Либо напиши агенту «выключи тестовую цену».

Пока тест включён, обычные покупатели всё равно платят 990.

## Ссылки с меткой

Подставь username бота:

- `https://t.me/<username>?start=tiktok`
- `https://t.me/<username>?start=youtube`
- `https://t.me/<username>?start=instagram`
- `https://t.me/<username>?start=story`

Человек получает кнопку «Открыть», а метка копится в статистике `/stats`. Первая метка не затирается следующими.

Ссылка, которая открывает сразу экран курса:

- `https://t.me/<username>?start=pixelverse_tiktok`

Так же можно `pixelverse_youtube`, `pixelverse_instagram`, `pixelverse_story`.

## Команды

В меню у всех:

| Команда | Что делает |
| --- | --- |
| `/start` | главный экран |
| `/mycourse` | список покупок, по кнопке файлы приходят снова |
| `/paysupport` | вопрос по оплате. Следующее сообщение уходит тебе |
| `/terms` | условия для цифровых продуктов |

Только с твоего аккаунта:

| Команда | Что делает |
| --- | --- |
| `/stats` | старты, покупки, конверсия, источники, продукты |
| `/broadcast` | текст рассылки, потом кнопка «Отправить» |
| `/refund <user_id> [продукт]` | вернуть звёзды |
| `/setfiles <продукт>` | загрузить файлы, закончить через `/done` |
| `/setimage <слот>` | заменить картинку |
| `/reply <id> текст` | ответить человеку в чат бота |
| `/cancel` | бросить текущий шаг |

На вопрос из `/paysupport` отвечай так: `/reply 123456 текст`.

Рассылка не уходит сразу всем. Она встаёт в очередь и раз в минуту отправляется пачкой по 20 человек: на бесплатном Cloudflare за один запуск можно сделать не больше 50 внешних запросов, и Telegram спокойнее принимает редкую отправку. Пока очередь пустая, крон ничего никому не пишет.

## Новый продукт

Продукт описывается в `src/catalog.ts`: короткое имя, текст кнопки, тексты экранов, цена в звёздах, заголовок счёта, файл обложки. Пока он не готов, поставь `hidden: true` — в каталоге его не будет, а `/setfiles` уже примет файлы. После деплоя меню, оплата и статистика подхватят его сами.

Оплата только звёздами (`XTR`). Другие способы для цифрового товара в боте Telegram запрещает.
